プライバシーポリシー

制定日:2026年11月9日

暮らしのお金ノート(以下「当アカウント」)は、本サイトおよび当アカウントが運営するYouTubeチャンネル・Xアカウント(以下あわせて「本サービス」)における個人情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

本サイトには会員登録や入力フォームはなく、閲覧だけで氏名やメールアドレスなどの個人情報を取得することはありません。お問い合わせの際に、Xのダイレクトメッセージでお送りいただいたお名前・アカウント名・内容などの情報を取得する場合があります。

2. 利用目的

取得した情報は、お問い合わせへの回答と、本サービスの改善のためにのみ利用します。

3. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく個人情報を第三者に提供することはありません。

4. アクセス解析・広告・アフィリエイトについて

本サイトでは現在、アクセス解析ツールや広告配信サービスを利用していません。今後これらのサービスやアフィリエイトプログラムを利用する場合は、Cookie等の利用方法と無効にする方法を含めて本ポリシーを改定し、本サイトでお知らせします。商品やサービスを紹介して報酬を受け取る場合は、各投稿に「PR」などの表記を行います。

5. Google API(YouTube Data API)の利用について

当アカウントは、運営者専用のツール「kurashimoney uploader」で、Googleが提供するYouTube Data APIを利用しています。

利用目的

運営者自身のYouTubeチャンネル「暮らしのお金ノート」に動画をアップロードし、公開日時を予約するため、およびアップロードした動画の公開状態やチャンネル情報を確認するためにのみ利用します。

アクセスするデータ

  • 動画のアップロード(権限:youtube.upload)
  • チャンネル名・チャンネルID、および当アカウントがアップロードした動画の公開状態・再生数などの情報(権限:youtube.readonly)

このツールを利用するのは運営者本人のみで、運営者が自身のGoogleアカウントで許可した範囲のデータだけを扱います。視聴者の皆さまや第三者のGoogleアカウントのデータにアクセスすることはありません。

保存・共有

Googleから発行された認証情報(アクセストークン等)は、運営者が管理する環境に保存し、上記の目的以外には使用しません。Googleのユーザーデータを販売したり、広告の目的で利用したり、第三者に提供したりすることはありません。なお、動画の作成と予約の作業には、AIアシスタント(Anthropic社のClaude)を利用しています。

Google APIから取得した情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

アクセスの取り消し

このツールに与えた権限は、Googleアカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。
